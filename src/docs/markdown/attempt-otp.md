Send the verification code that is sent to user's email to this API to approve the action that you want to do. After that a verification code is approved, an action code will be sent in response body. That action code is valid for only 5 minutes and can be used only once to do related actions. For example an action code that is related to an OTP with type of `account_verification`, should be sent to an endpoint that is related to verifying an account.
